# Fotos

No edites esta carpeta a mano. Usá **`admin.html`** (el panel de administración) para:

- Agregar, editar, eliminar y reordenar platos del menú — nombre, descripción, precio,
  etiqueta y foto de cada uno.
- Subir fotos reales del local / la plancha para el carrusel de "Nuestra historia".

El panel sube las fotos acá con el nombre correcto automáticamente y actualiza
`menu.json` / `about.json`, que es lo que `index.html` lee para armar el sitio.

Esta carpeta arranca vacía a propósito: el sitio se lanzó sin fotos reales del local
todavía. Hasta que se suban, el menú muestra un ícono de placeholder y la sección
"Nuestra historia" muestra un cartel en vez del carrusel.
